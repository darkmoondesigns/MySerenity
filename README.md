# MySerenity – Schnelle Notizen App

Eine einfache, lokale Notizen-App für Meetings und Themenorganisation – ohne Account, ohne Backend, ohne komplexen Editor.

## Features

- Themen anlegen (z. B. "Kunde A", "Projekt X", "Privat")
- Pro Thema mehrere Meeting-Notizen
- Schnelles Erstellen neuer Meeting-Notizen
- Volltextsuche innerhalb eines Themas
- ToDo-Liste pro Notiz (Checkboxen)
- Automatisches Speichern im Browser (`localStorage`)
- Tastenkürzel:
  - `Alt + N`: Neue Meeting-Notiz
  - `Ctrl + S`: Speichern

## Start

Einfach `index.html` im Browser öffnen.

> Hinweis: Daten bleiben lokal im Browser (`localStorage`) auf diesem Gerät/Browser.
